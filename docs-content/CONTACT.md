## Best Use of Each Channel

- GitHub: bugs, feature requests, roadmap discussions, and code contributions
- Email: private questions, sponsorship, partnership, or sensitive moderation issues
- Discord: quick help, design discussion, experiments, demos, and community chat
- Google Group: announcements, longer-form discussion, and durable public threads
- X: public updates, release highlights, and project visibility
- Bluesky: public updates, release highlights, and community-facing announcements

## When Reporting Issues

Please include:

- Lumina version
- target profile (`js`, `wasm-web`, or `wasm-standalone`)
- operating system and browser/runtime
- minimal reproduction
- expected result and actual result

## Community Expectations

- Be respectful and constructive
- Prefer reproducible reports over vague complaints
- Keep security-sensitive disclosures private until coordinated

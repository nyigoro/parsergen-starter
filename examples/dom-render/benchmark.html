DOM Benchmark Harness

This page now splits the workload into multiple scenarios so we can see where Lumina is still paying whole-tree patch costs and where its reactive primitives are already competitive.

Idle
  • Whole-list patch measures raw JS fallback render cost plus the compiler-promoted Lumina path.
  • Indexed list patch measures a whole-array signal fanning out into stable row signals.
  • Keyed signal list patch measures keyed row signals plus stable keyed DOM identity.
  • Compiled Lumina rows measure the compiler-lowered DOM path with static template hoists and direct live text bindings.
  • Initial mount measures first render cost for a 1,000-row list.
  • Keyed reorder measures moving keyed rows without changing content, including the compiled keyed-list path.
  • Fine-grained row update measures direct row-level reactivity instead of full rerender.
